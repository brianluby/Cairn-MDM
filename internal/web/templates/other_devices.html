Cairn cannot renew the certificate or remove the profile; it shows when each certificate expires so you can replace it in time.

Install a downloaded profile

A downloaded profile works once, for ten minutes. Download it on the device that will install it, signed in to Cairn there, so the file is never copied around. Downloading again makes the earlier file useless.

Apple Vision Pro. Open this page in Safari on the headset and download. Then open Settings, General, VPN & Device Management, and install the profile.

HomePod or Apple Watch. Set the device up on another network first. Open this page in Safari on the iPhone it is paired with and download. When the iPhone asks which device the profile is for, choose the HomePod or the watch.

Apple TV. An Apple TV can enroll in MDM instead; use this only for one that cannot.

Downloading needs an MFA code verified in the last five minutes. The device itself must reach this server over HTTPS while the profile installs; on a restricted network such as one for IoT devices, allow that first, or the install ends in a network error.
